# AI-Powered Synthetic User Research Platform

An AI-powered platform that generates synthetic user personas, simulates surveys and interviews, extracts insights, and creates research reports.

**Product under research:** Smart Student Planner

### Features
- AI-generated synthetic personas
- Simulated surveys and interviews
- AI-powered research insights
- SQLite database storage
- PDF report generation

### Tech Stack
Python, FastAPI, LangChain, LangGraph, Google Gemini, SQLite, ReportLab.

### Disclaimer
All personas and responses are AI-generated simulations, not real user research.
